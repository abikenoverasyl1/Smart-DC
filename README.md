# Smart Data Center — Деректер орталығын басқару жүйесі

IoT технологиялары пәні бойынша СОӨЖ, №60 тақырып.
Орындаған: Абикен Ерасыл, ИС 23-11.

Сервер бөлмесіндегі температураны, ылғалдылықты, сервер жүктемесін және электр желісінің кернеуін бақылайтын, салқындату жүйелерін басқаратын веб-платформа. Нақты датчиктер қолданылмайды: олардың мәндері бағдарламада симуляцияланады.

## Мүмкіндіктері (СОӨЖ талаптарына сәйкес)

| № | Талап | Сайтта қалай орындалған |
|---|-------|-------------------------|

| 8 | Автоматтандыру | 5 ереже «Егер … онда …» (шекті мәндерін өзгертуге болады) |

## Іске қосу

**1. Компьютерде тексеру.** Сайт ES-модульдерді қолданады, сондықтан `index.html` файлын екі рет басып ашу жеткіліксіз, жергілікті сервер керек:

- VS Code → **Live Server** кеңейтімі → `index.html` → *Open with Live Server*, немесе
- терминалда: `python -m http.server 8000` → браузерде `http://localhost:8000`

Firebase бапталмаса, сайт **жергілікті режимде** жұмыс істейді (деректер браузерде сақталады).

**2. Firebase қосу (бұлт).**

1. https://console.firebase.google.com → **Add project** → жоба атауы, мысалы `smart-dc`.
2. **Build → Firestore Database → Create database** → аймақ `eur3` → **Start in test mode**.
3. **Project settings (⚙) → Your apps → Web (</>)** → қосымшаны тіркеу → `firebaseConfig` объектісін көшіру.
4. `js/firebase-config.js` ашып, `export const firebaseConfig = null;` орнына көшірілген объектіні қою.
5. Сайтты қайта ашу: жоғарғы мәзірде **«Firebase · бұлт»** жасыл белгісі шығады.

Firestore-да автоматты түрде `datacenter/state`, `readings`, `events` жинақтары пайда болады.

> Test mode ережелері 30 күннен кейін бітеді. Қорғауға дейін Firestore → **Rules** бөліміне мынаны жазыңыз:
> ```
> rules_version = '2';
> service cloud.firestore {
>   match /databases/{database}/documents {
>     match /{document=**} { allow read, write: if true; }
>   }
> }
> ```
> (Бұл оқу жобасына арналған; нақты жүйеде авторизация қажет.)

**3. Интернетке жариялау (Firebase Hosting).**

```
npm install -g firebase-tools
firebase login
firebase init hosting     # public directory: .   single-page app: No
firebase deploy
```

Нәтижесінде `https://<жоба-атауы>.web.app` сілтемесі шығады. Баламасы: файлдарды GitHub-қа жүктеп, **Netlify** немесе **Vercel** арқылы жариялау.

## Қорғауда не көрсету керек

1. **Датчиктер**: температура жүгірткісін 30°C-қа апару → өлшеуіш сарғаяды, «Ескерту» хабарламасы шығады.
2. **Автоматика**: сол сәтте Кондиционер 2 «Турбо» режимде өздігінен қосылады, журналға жазылады.
3. **«Желі өшті» сценарийі**: кернеу 0 V → апаттық ескерту → UPS қосылады → батарея азая бастайды.
4. **Құрылғыларды басқару**: желдеткішті «Жоғары» режимге ауыстыру → жылдамырақ айналады.
5. **Бұлт**: Firebase Console → Firestore ашып, `datacenter/state` құжатындағы мәндердің өзгергенін көрсету. Сайтты телефонда да ашсаңыз, өзгерістер екі құрылғыда бірдей көрінеді.
6. **Мониторинг**: график қойындыларын ауыстыру, статистика (мин/орташа/макс), қуат диаграммасы.

## 3D эффекттер

- **3D модель** (басты бет): 2 сервер стойкасы, кондиционер және UPS. Кітапханасыз, тек CSS 3D (`transform-style: preserve-3d`) арқылы жасалған. Модель деректерге байланысты: стойка өшсе — сөнеді, кондиционер қосулы болса — желдеткіш айналып, салқын ауа бөлшектері ағады, температура дисплейде көрінеді, ескерту кезінде еден жарығы сарғаяды/қызарады.
- **Камера** тышқанға және бетті айналдыруға қарай бұрылады.
- **Карточкалар** тышқанға қарай 3D-де еңкейеді.
- **Бөлімдер** айналдырғанда 3D-де «ашылады», график қойындысын ауыстырғанда аударылады.

## Тақырып және тіл

- Жоғарғы мәзірдегі ☀/☾ батырмасы — қараңғы және жарық тақырып. Таңдау браузерде сақталады; алғаш ашқанда жүйенің баптауы (prefers-color-scheme) қолданылады.
- Тіл тізімі — қазақша, русский, English. Бет қайта жүктелмей аударылады. Журналдағы оқиғалар кілт + параметр түрінде сақталады, сондықтан ескі жазбалар да таңдалған тілде көрсетіледі.

## Автоматика ережелері

| Ереже | Шарт | Әрекет |
|-------|------|--------|
| R1 | Температура > 27°C | Кондиционер 2 «Турбо» режимде қосылады |
| R2 | Температура < 20°C | Кондиционер 2 өшіріледі |
| R3 | Жүктеме > 80% | Желдеткіштер «Жоғары» режимге ауысады |
| R4 | Кернеу < 200 V | UPS қосылады (желі қалпына келгенде өшеді) |
| R5 | Ылғалдылық > 60% | Кондиционер 1 «Құрғату» режиміне ауысады |
